# Portfólio — Eduardo Machado Ferla

## Como usar
Abra `index.html` no navegador. Tudo funciona offline, sem build.

## Personalizações pra você fazer

### 1. Foto de perfil
Em `index.html`, procure por `<!-- Coloque uma foto sua -->` e troque
`<span>EMF</span>` por `<img src="foto.jpg" alt="Eduardo">`.
Coloque o arquivo `foto.jpg` na mesma pasta.

### 2. Links sociais (GitHub / LinkedIn)
No hero, troque os `href="https://github.com/"` e `href="https://linkedin.com/"`
pelos seus perfis reais.

### 3. Currículo em PDF
Coloque um arquivo `curriculo.pdf` na pasta. O botão "Baixar CV" já aponta pra ele.

### 4. Formulário de contato funcional (grátis)
1. Crie conta em https://formspree.io
2. Crie um novo form e copie o ID
3. Em `index.html`, troque `https://formspree.io/f/SEU_ID_AQUI` pelo seu ID
4. Pronto — emails chegam direto no seu Gmail

### 5. WhatsApp
O número já está configurado (`5545984314554`). Se mudar, atualize em `.wa-fab`.

### 6. Links dos projetos
Em cada `<article class="project">`, adicione um `<a>` apontando pro GitHub
ou demo. O Jarvis já tem botões prontos — só trocar o `href="#"`.

## Hospedagem grátis
- **GitHub Pages**: suba pro GitHub e ative Pages nas configurações
- **Netlify** / **Vercel**: arraste a pasta no site e pronto
- **Domínio próprio**: registre em registro.br (.com.br ~ R$40/ano)
